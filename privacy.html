Privacy Policy

Last updated: October 2026

Agenda Bot is a personal, non-commercial tool used only by its developer. This policy explains how it handles Google user data.

Google user data the app accesses

The app requests one Google permission: https://www.googleapis.com/auth/calendar.events. It uses it only to create calendar events, with one attendee chosen by the developer, in the developer's own Google Calendar. The app does not read, list, copy or analyse existing calendar events.

How the data is used

The only information sent to Google Calendar is what the developer types to describe an appointment (title, date, time, optional notes) and the email address of the attendee configured by the developer. Google Calendar sends the invitation email to that attendee. The text the developer types to describe an event is processed by an AI assistant that extracts the title and the date; the app does not send existing Google Calendar data to that assistant.

Storage

The app stores a Google OAuth refresh token and the OAuth client credentials in a configuration file on a private home server controlled by the developer. No other Google user data is stored. No data is kept in any external database.

Sharing

The app does not sell, rent, share or transfer Google user data to third parties, and does not use it for advertising, profiling or analytics.

Retention, revocation and deletion

The refresh token is kept until it is revoked. Access can be revoked at any time at https://myaccount.google.com/permissions. Events created by the app can be deleted directly in Google Calendar.

Google API Services User Data Policy

Agenda Bot's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

This policy may be updated if the app changes. The date above shows the latest revision.

Contact

For questions about this policy, open an issue on the GitHub repository that hosts this page.
